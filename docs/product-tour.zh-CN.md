# 在本地体验 CampusPulse

[English](product-tour.md) · [返回 README](../README.zh-CN.md)

这份指南带你体验课程项目的学生、组织者和管理员视角。演示运行在你自己的电脑上；本仓库未提供托管的公开线上演示站点。

演示数据只初始化一次，活动日期可能已经过期，重启也不会刷新。部分活动可能已结束、满员或尚待审核，请以页面实际状态为准。

1. **启动本地演示。** 先按[下载运行](../README.zh-CN.md#下载运行)准备 Docker、Python 和对应系统的环境，再在项目根目录运行：

   ```bash
   python3 tools/dev.py init
   python3 tools/dev.py up
   ```

   等待启动完成后访问 [http://127.0.0.1:8125](http://127.0.0.1:8125)，应能看到带有 **登录** 按钮的 CampusPulse 欢迎页。首次构建可能需要数分钟；遇到问题可查看 README 的[常见启动问题](../README.zh-CN.md#常见启动问题)。

2. **选择语言，以学生身份登录。** 使用页面的 **中文 / EN** 切换器，再点击 **登录**，使用 [README 演示账号表](../README.zh-CN.md#下载运行)中的学生账号。

   界面和已翻译的演示内容会随语言切换，当前浏览器会保存选择。姓名、聊天消息和用户自行填写的内容可能保留原文。中文底部导航依次是 **发现、活动、组队、消息、我的**。

3. **发现并收藏一个活动。** 打开 **活动**，选择分类或搜索标题、标签，点开一条结果，查看时间、地点、介绍和名额。点击详情页底部的书签图标。

   书签变为实心；进入 **我的 → 我的收藏**，即可再次找到它。还可在 **我的 → 兴趣标签管理** 中设置兴趣，用于首页推荐。

4. **在允许报名的活动中尝试申请。** 点击 **立即报名参与**，填写所需报名资料并提交。本地体验可使用虚构的联系方式。

   页面显示 **报名审核中**，等待发布者处理；**我的 → 我参加的活动** 会保留记录。提交不等于审核通过。如果演示活动已经过期，可按第 8 步发布一个未来活动后再体验。

5. **体验组队及独立的入队审批。** 打开 **组队**，筛选或搜索队伍，查看介绍和成员情况。选择仍在招募、有空位且自己尚未加入的队伍，点击 **申请加入** 并提交自我介绍。

   申请进入待审核状态，可在 **我的 → 我参加的组队** 中跟踪，等待队长处理。加入队伍不会自动报名关联活动，活动报名通过也不会自动通过入队申请。还可点击 **发起组队** 创建队伍，再从 **我的 → 我发起的组队** 查看队长管理工具。

6. **查看沟通入口和通知。** 在活动详情点击 **联系发布人**，或在队伍卡片点击 **联系发起者**。新私聊请先发送一条虚构的测试消息，再返回 **消息** 列表；仅打开聊天页不会产生消息历史。打开已有会话查看历史记录，点击 **查看更多通知** 查看通知。

   队伍群聊要求当前有效成员身份；活动群聊需由发布者开启，并具备相应权限，例如报名已通过。通知帮助了解申请进展，最终状态仍以活动或队伍页面为准。

7. **无需模型密钥，直接咨询客服。** 点击悬浮耳机按钮进入 **智能客服**，输入“如何加入队伍？”。

   默认会收到标注 **帮助文档** 的本地指南及参考链接，无需 API Key。可选的模型生成由部署者按 README 配置。若想体验工单，描述一个示例问题并明确点击 **转人工服务**，随后在 **支持工单** 中查看回复和状态；仅提问不会自动创建工单。

8. **切换组织者和管理员视角。** 在 **我的 → 退出登录** 后，使用 [README](../README.zh-CN.md#下载运行)中的组织者或管理员账号登录。

   组织者打开 **我的 → 我发布的活动**，进入某个活动的管理页，查看待审批报名、已通过人员和群聊设置。处理待审批报名后，学生端可看到状态变化。入队申请由队长通过 **我发起的组队** 单独处理。

   管理员打开 **我的 → 管理后台**，浏览 **活动治理、用户治理、精选活动运营位、标签体系、支持工单**，查看审核和客服处理工具。给示例工单回复后，学生可在自己的工单历史中看到回复。

   若原有活动日期已过期，可由组织者点击 **发布活动**，设置未来日期和可用名额。新活动先进入待审核状态，由管理员在 **活动治理** 中审核通过，再切回学生报名。需要同时保留不同角色时，可使用彼此独立的浏览器用户配置。

发现步骤不清楚或功能异常，可[提交 Issue](https://github.com/xkkkkkkm/campuspulse/issues/new/choose)，写明页面、操作步骤和预期结果。参与文档、翻译或代码改进前，请阅读[贡献指南](../CONTRIBUTING.zh-CN.md)。也欢迎用 Star 收藏仓库，方便下次回来。
