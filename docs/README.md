## Historical course materials

The [earlier engineering assessment](engineering-assessment.zh-CN.md), Chinese demonstration notes, `architecture/uml/`, `software_project_management/markdown/`, and `dify/` retain the project's development context. Some describe earlier behavior, proposed integrations or course-time plans. They are not acceptance evidence for the current release and may mention removed tools or unimplemented model approaches. Use the current documents, source code and [remediation status](remediation-status.md) to evaluate present behavior.

Course `.docx`/`.pptx` files, delivery archives, generated reports, local uploads and credentials are excluded from the public source release. Current instructions do not depend on those files. Historical source material is retained without asserting university endorsement or attributing collaborative work to one individual.
