## 双语内容与 LangGraph 更新

已为 40 条活动、33 条队伍提供原文校验的英文译文，适配封面、标签、详情、个人记录与编辑，英文标题及标准标签支持搜索。V7 绑定种子身份，V8 增加会话与模型额度，V9 只更新未编辑的旧客服演示描述；用户编辑保留。

客服由私有 FastAPI/LangGraph 服务处理，包含 15 条双语指南、多轮追问、引用和可选模型生成。Java 管理会话归属、列表/恢复/删除、45 秒 lease、单用户限流和原子日额度；陌生人不能读取会话，匿名不能请求模型生成，未知问题只建议用户显式提交工单。

LangGraph 单元/HTTP/模拟提供商测试 **52 项通过**，47 个 Python 运行依赖审计没有返回已知漏洞；真实外部模型尚未调用。此前三服务的隔离 prod 和恢复演练记录保留为前一版证据，当前默认四服务已运行。

## 明确边界

- 单 API 实例：SSE、短期票据和通用限流状态在内存，多实例需共享协调、事件投递及存储设计。
- 匿名 IP 限流看到代理 socket 地址；已登录客服用户采用各自用户额度，其他 IP 桶仍可能共享；公开部署需要可信代理/边界策略及 HTTPS。
- **SMTP 与可选模型尚未完成真实外部服务联调**。LangGraph 本地检索和显式工单不依赖模型密钥；正式邮箱流程仍需验证服务商配置。
- ML 联调使用真实 MySQL 和受控测试数据。新演示库通常真实观察不足，使用规则推荐；不宣称真实校园准确率、因果提升或生产使用量。
- 未记录真实规模压测、QPS、跨地域/高可用演练、外部安全审计或完整无障碍认证。
- 已有健康检查、数据库感知 readiness、私有指标和结构化日志，但不能据此推断已有完整监控告警、持续备份计划或公开发布。
